# Blocos Simples — página pública

Site de suporte e política de privacidade de Lucas Takeo. Contato: blocossimples.suporte@gmail.com.

Somente conteúdo público neste repositório. Código, APKs, ferramentas e chaves do jogo ficam fora dele.

## Publicação

Em Settings → Pages → Build and deployment → Source, selecione **GitHub Actions**. Depois abra Actions → Publicar página → Run workflow. O workflow também executa em pushes para main.

Endereço esperado após publicação (confirmar execução verde): https://takeo-ishikawa.github.io/blocos-simples-site/
Política: https://takeo-ishikawa.github.io/blocos-simples-site/privacidade.html

Não cadastrar o endereço no AdMob antes de abrir a página sem login e confirmar sua disponibilidade. Publicar esta página não configura mensagens no AdMob nem libera anúncios reais.

## Conteúdo

A política descreve a versão de teste atual. Antes do lançamento comercial, revisar o texto junto das cópias dentro do jogo e das declarações da loja. Não modificar a data sem revisar o conteúdo. O site não usa analytics, formulários ou scripts de publicidade; hospedagem pelo GitHub Pages está sujeita à política do GitHub.

Não publicar app-ads.txt neste subdiretório como se validasse o domínio: o AdMob procura esse arquivo na raiz do domínio do site de desenvolvedor. Preparar o domínio/raiz apropriados em uma etapa separada.
